Family History

Build a pedigree and configure the diseases and colours used to display it.

About this demo

Hover over an individual to add partners, parents, siblings and children, or click the widget to edit their details. Use the Diseases button to add or remove diseases and change the colours used to display them. The disease configuration is kept in the browser's local storage. See the developer notes and the examples for more ways to configure pedigreejs.
